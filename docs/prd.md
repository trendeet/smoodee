## 1. 제품 요약

- **제품명(가칭)**: smoodee
- **한줄 요약**: **OAuth2 로그인 후, 개인(컬러워크)·그룹(하루공유) 템플릿을 단계형 플로우로 빠르게 완성하고 다운로드/Export하는 제작 웹앱**
- **핵심 가치**
    1. 템플릿 제작의 반복 작업(레이아웃/규격/디자인)을 자동화합니다.
    2. 진행중 작업을 안전하게 저장하고, 언제든 재개할 수 있게 합니다(“진행중 템플릿” 탭).
    3. 그룹 제작은 시간 슬롯·알림·수집·합본을 한 화면에서 운영 가능하게 합니다.

---

## 2. 문제 정의

- 유행 템플릿 제작은 포맷이 정해져 있어 보여도 실제로는 다음 비용이 큽니다.
    - 사진/영상 비율·프레임 맞춤, 잘림 방지
    - 텍스트/스티커/여백의 “감각적인 완성도” 구현
    - 그룹일 경우 업로드 수집, 시간 맞추기, 미제출자 관리, 합본 편집
- 사용자는 “클릭 몇 번으로 완성”을 기대하지만 실제 과정이 번거로워 중도 이탈합니다.

## 3. 목표 / 비목표

### Goals (MVP)

- 개인 컬러워크: 템플릿 선택 → 다운로드까지 **평균 2~3분 이내**
- 개인 템플릿 완성(다운로드) 전환율 **35%+**
- 그룹 생성 → 최종 Export 전환율 **20%+**
- 알림 옵트인 유저 기준 슬롯 업로드 완료율 **50%+**

### Non-goals (MVP)

- 인스타 자동 게시(Posting API 연동)
- 템플릿 마켓/커뮤니티(업로더 생태계)
- 고급 편집(키프레임/정교 합성/자막 타임라인 편집기)

## 4. 대상 사용자

- **그룹 제작형**: 친구 n명과 하루를 시간대별로 모아 “합본 영상”을 만들고 싶은 사용자
- **가벼운 크리에이터**: 편집은 싫지만 결과물 퀄리티는 포기 못 하는 사용자

## 6. 핵심 사용자 시나리오

### S1) 로그인(OAuth2) 공통

1. 랜딩 → **OAuth2 로그인/가입**
2. 추가 정보 입력 폼 없음(바로 진입)
3. 이후 모든 작업은 계정 기반으로 저장/복구 가능

---

### S2) 개인 템플릿: 컬러워크(ColorWalk)

**목표:** 감각적 디자인이 적용된 “인스타 공유용 이미지”를 빠르게 다운로드합니다.

1. Home → **컬러워크 템플릿 선택**
2. **사용법 알아보기 / 건너뛰기**
    - 알아보기: 3~5장 슬라이드(예시/주의점/완성샷)
3. **색 선택 화면**
    - 3가지 색(팔레트) 중 1개 선택
    - **새로고침(Shuffle) 버튼**으로 3색 세트 재생성(원하는 색 나올 때까지)
4. **사진 개수(레이아웃) 선택**
    - 2×2(4장) 또는 3×3(9장)
5. **프레임 업로드 화면**
    - 프레임별 업로드(드래그/모바일 선택)
    - 이 화면에서 **“나가기”** 시 현재 진행 상태가 **진행중(개인)** 탭에 저장됩니다.
6. **완성하기**
    - 서비스 고유의 감각적인 디자인(여백/타이포/스티커/필름 프레임 등 프리셋) 자동 적용
7. **다운로드**
    - 기본: Story 9:16 (MVP)
    - (옵션/후순위): Feed 4:5 / 1:1

---

### S3) 그룹 템플릿: 하루 일상 공유(Daily Share)

**목표:** 인원수 기반 레이아웃으로 합본 영상을 자동 생성/Export합니다.

1. Home → **그룹 템플릿(하루공유) 선택**
2. **그룹 생성**
    - 입력: 그룹 이름, 인원수
    - 템플릿 기반 생성 플로우를 기본으로 합니다.
    - (대안 플로우 지원) “그룹 먼저 생성” 진입 시, 마지막 단계에서 템플릿 선택 제공
3. **친구 초대**
    - 초대 링크/코드 공유
4. 그룹 내 제공 기능
    - **채팅**
    - **인증현황(업로드 제출 현황/미제출자)**
5. **시간 슬롯 커스텀**
    - 사용자가 원하는 시간 추가/삭제(예: 09/12/15/18/21)
6. “진행” 누르면
    - 각 시간에 맞춰 **업로드 알림(푸시/PWA)** 발송
7. 각 멤버는 해당 시간에 접속해 **짧은 영상 업로드**
8. **미리보기(Preview)**
    - 완성 전이라도 지금까지 업로드된 영상이 최종 결과에서 어떻게 배치되는지 확인
9. **완성/Export**
    - 최종 영상은 **인원수만큼 Row로 분리된 레이아웃**로 합본
    - (예시) 시간 슬롯 단위로 세그먼트가 진행되며, 각 세그먼트에서 멤버별 영상이 세로로 쌓여 표시
10. 다운로드/공유

## 7. 템플릿 카탈로그 (MVP)

> MVP는 **2종만** 제공합니다. (개인 1 + 그룹 1)
> 

### T1) 컬러워크 (개인)

- 입력: 팔레트(3색 중 선택) + 사진 4장(2×2) 또는 9장(3×3)
- 출력: 인스타 공유용 이미지(기본 Story 9:16)
- 자동화(핵심)
    - 새로고침으로 팔레트 랜덤 제안
    - 선택 레이아웃(2×2/3×3) 기반 자동 그리드/여백
    - 감각적 디자인 프리셋 자동 적용(타이포/스티커/프레임)

### T2) 하루 일상 공유 (그룹)

- 입력: 시간 슬롯 m개(사용자 커스텀) + 슬롯별 멤버 영상(짧은 클립)
- 출력: 9:16 합본 영상(Export)
- 자동화(핵심)
    - 슬롯 시간 기반 알림 발송
    - 제출 현황/미제출자 관리
    - 합본 시 **Row = 멤버 수** 레이아웃 적용
    - 미리보기 제공(완성 전 중간 상태 확인)

## 8. 기능 요구사항 (Functional Requirements)

### 8.1 인증/계정 (필수)

- OAuth2 로그인/가입 지원
- 2차 정보 입력 Form 없음
- 세션 유지(토큰 기반) 및 로그아웃

### 8.2 진행중 템플릿(Projects)

- “진행중 탭”에서 개인/그룹을 분리해 리스트 제공
- 상태 관리
    - 개인: `초기설정(색/레이아웃)` → `업로드중` → `완료`
    - 그룹: `생성됨` → `시간설정` → `진행중(알림/업로드)` → `완료(Export 가능)`
- Resume/삭제/공유(그룹 링크) 제공

### 8.3 개인 컬러워크 플로우

- 사용법 안내(슬라이드) + 건너뛰기
- 팔레트 3색 제안 + Shuffle(새로고침)로 재생성
- 2×2 / 3×3 선택
- 프레임 업로드(필수 개수 강제, 진행률 표시)
- “나가기” 시 진행중 저장(자동 저장 + 명시적 저장)
- 완성 시 디자인 프리셋 렌더 → 다운로드

### 8.4 그룹 하루공유 플로우

- 그룹 생성(이름/인원수) + 템플릿 연결
- 초대 링크/코드
- 채팅
- 인증현황(슬롯별, 멤버별 제출 상태)
- 시간 슬롯 커스텀(추가/삭제/정렬)
- 슬롯 시간에 맞춘 알림 발송 및 업로드 화면 딥링크
- 미리보기(현재까지 업로드된 결과 기반)
- 완료 시 합본 렌더 → Export

### 8.5 업로드(공통)

- 사진/영상 업로드(모바일 파일 선택 우선)
- 파일 검증(해상도/용량/길이), 실패 재시도
- 업로드 진행률 및 에러 가이드

### 8.6 렌더링/내보내기

- RenderJob 상태: QUEUED / RUNNING / SUCCEEDED / FAILED
- 실패 사유 제공 + 재시도
- 결과물 다운로드(고화질)

## 9. 알림(PWA/Web Push) 요구사항 (그룹 우선)

### 9.1 옵트인 UX

- 그룹 진행 단계에서 “알림 받기” 유도
- 권한 요청(사용자 제스처 기반) → 구독 저장

### 9.2 발송 트리거(그룹)

- 슬롯 시간 도달 알림(업로드 요청)
- 마감 임박 리마인드(선택)
- 최종 합본 완료 알림

### 9.3 스팸/운영 정책

- 1일 최대 발송 횟수 제한
- 야간 제한(예: 23:00~08:00)
- 미제출자 중심 리마인드(제출자 제외)

## 11. 비기능 요구사항(NFR)

- 성능: 플로우 전환/미리보기 체감 1초 내 목표(네트워크 제외)
- 안정성: 렌더 실패율 < 2%, 재시도 UX 제공
- 보관 정책(비용/프라이버시)
    - 진행중 프로젝트는 기본 보관, 결과물은 TTL 또는 보관함 정책으로 관리(초기엔 7~30일 등 단순 정책 권장)
- 보안: 서명 URL + TTL, 접근 제어(그룹 멤버만 접근)

## 12. 측정 지표

- 로그인 퍼널: 랜딩 → OAuth 완료율
- 개인: 템플릿 선택 → 색 선택 → 업로드 시작 → 완성하기 → 다운로드
- 그룹: 생성 → 초대 수락 → 알림 옵트인 → 슬롯 업로드율 → Export 완료율
- 알림: 옵트인율 / 클릭률 / 클릭 후 업로드 완료율
- 이탈 지점: 팔레트 화면, 업로드 화면, 렌더 대기 구간

## 13. MVP 범위 / 로드맵

### MVP(v0)

- OAuth2 로그인(추가 폼 없음)
- 진행중 탭(개인/그룹 분리)
- 개인: 컬러워크(팔레트 셔플, 2×2/3×3, 저장/재개, 다운로드)
- 그룹: 하루공유(그룹 생성/초대/채팅/인증현황/시간 커스텀/알림/업로드/미리보기/Export)
- 렌더 큐 및 실패 처리

### V1

- 개인 결과물 규격 확장(4:5, 1:1), 프리셋 다양화
- 그룹 마감/리마인드 정책 고도화(미제출자 대상 강화)
- 템플릿 추가(개인 템플릿 1~2종)

### V2

- 템플릿 빌더(운영 효율화)
- 그룹 결과물 커스터마이징(표지/자막/배경음 프리셋)
- 고급 보관함/검색/공유 옵션

---

## (옵션) V1~V2 확장 아이디어 (현재 구조에 맞춘 12개)

1. 팔레트 셔플에 “좋아요/싫어요” 피드백을 넣어 개인 취향 기반 추천 강화
2. 컬러워크 완성 화면에 “인스타 캡션/해시태그 자동 생성” 버튼
3. 2×2/3×3 외에 “필름 프레임/폴라로이드 프레임” 프리셋 추가
4. 그룹 시간 슬롯에 “반복(매일/주말)” 템플릿 저장 기능
5. 그룹 미제출자만 콕 집어 보내는 스마트 리마인더
6. 업로드 품질 검사(너무 어두움/가로 영상 경고/길이 초과 자동 트림)
7. 그룹 미리보기에서 빈 슬롯은 플레이스홀더로 표시하고, 클릭 시 업로드로 바로 이동
8. 방장용 운영 패널(마감 연장/조기 마감/재렌더/멤버 강퇴)
9. 그룹 완료 영상 첫 장면에 자동 표지(그룹명/날짜/멤버) 생성
10. 업로드 알림 외 “친구가 업로드했어요” 피드백 알림(과도하지 않게 옵션)
11. 진행중 탭에 “마지막 수정시간/진행률(4/9 업로드)” 표시
12. 결과물 공유 링크에 접근 제어(멤버만 보기 / 링크 소유자만 다운로드)
